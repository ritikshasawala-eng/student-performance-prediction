# Student Performance Prediction and Clustering System

## Project Overview
This mini project combines supervised and unsupervised machine learning to analyze student performance.

## Objectives
- Predict student final marks using Linear Regression.
- Group students with similar characteristics using K-Means Clustering.
- Visualize student performance and model predictions.

## Technologies Used
- Python
- Google Colab
- Pandas and NumPy
- Matplotlib
- Scikit-learn

## Machine Learning Algorithms
1. **Supervised Learning:** Linear Regression
2. **Unsupervised Learning:** K-Means Clustering

## Dataset
A simulated dataset of 200 students containing study hours, attendance, previous marks, assignment scores, and final marks.

## Evaluation
The supervised model is evaluated using MAE, MSE, RMSE, and R² score.

## How to Run
1. Download the `.ipynb` notebook from this repository.
2. Open [Google Colab](https://colab.research.google.com/).
3. Select File → Upload notebook.
4. Upload the notebook and run the code cells in order.
